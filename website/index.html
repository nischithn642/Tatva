Stage 05 · Generate

Build the RISC-V binary and measure it

TVM emits C99, GCC links it, QEMU runs it — baseline and optimized, in the same run.

The RISC-V toolchain is not installed, so there is nothing to compile with.

Compile and benchmark

A first run takes a few minutes — two full builds and two emulated runs.

Timings are QEMU system-mode, -icount shift=0, cycles converted at a nominal 100 MHz. Not silicon.
